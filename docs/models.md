# Models

Which Hugging Face repo each model name downloads. `kapitsa serve --model 27b` and `kapitsa pull 27b` take any alias in the first column of the first table; a variant is the alias plus `:variant` (`27b:8bit`). The repos and revisions are the catalog's ([src/hub/catalog.cpp](../src/hub/catalog.cpp)), so every download is the same bytes.

This page is written by [tools/models_table.py](../tools/models_table.py) from the catalog and checked in CI: after a catalog change run `python3 tools/models_table.py` and commit the result. For what each model is and which Mac it fits, see [Models and downloads](usage.md#models-and-downloads) and `kapitsa doctor`.
